# cursor

## Skills

- [`dp`](.cursor/skills/dp/SKILL.md) — 写大众点评评价 / 探店笔记

### 怎么点选（不用打全名）

1. 打开 **Agent** 聊天（不是普通 Chat / Cmd+K）
2. 输入 **`/`**（不是 `@`）
3. 在弹出列表里点选 **`dp`**
4. 再输入店名和体验

`@` 主要用来引用文件/代码，skill 一般在 `/` 菜单里。

若列表里没有：确认当前项目里有 `.cursor/skills/dp/SKILL.md`，然后 **Developer: Reload Window** 或新开一个 Agent 对话再试。
