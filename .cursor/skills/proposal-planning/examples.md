# 输出范例（供策划对照，勿原样照抄）

## 输入

女朋友比较内向，不喜欢人多围观。我们在杭州，预算装饰和晚餐大概 2000，戒指已有。认识是在图书馆，第一次约会去了西湖。想这周末找个日落时间，不要太夸张。

## 方案总览应体现

- 主推贴合「内向 + 西湖回忆 + 日落」：私密户外或熟悉角落，而非广场乐队
- 备选：居家布置 / 安静餐厅靠窗位
- 明确不含戒指费用的预算拆分

## 主推方案示例要点

- 方案名有画面（如「断桥附近 · 日落只有我们」），不要叫「浪漫求婚方案 A」
- 时间线含：提前踩点、如何自然约出门、求婚节点、事后吃饭
- 台词含图书馆或西湖的具体回忆，提问句短
- Plan B：下雨改室内咖啡厅靠窗位或回家布置
- 风险：周末人流、是否需要提前看天气与备伞

## 短版台词语气示例

「还记得第一次在西湖边走，你说桥上看日落的人太多。今天人少一点，我想把那天没说完的话说完——这些年和你从图书馆走到现在，我想一直走下去。你愿意嫁给我吗？」

## 反例（不要这样）

- 找人偷偷录视频当众起哄
- 「如果你拒绝我就跪一夜」
- 通篇「苍天为证」「余生请多指教」堆砌，没有你们的故事
