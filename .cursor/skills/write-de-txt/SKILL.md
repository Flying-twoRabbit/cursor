# 写入本机 D:\ / E:\ 文本文件

按固定路径与固定文案，在**用户本机 Windows 磁盘**生成两个 txt。不要改内容、不要换文件名。

## 何时启用

- 用户要求在 D 盘 / E 盘写这两个文件
- 用户提到「李逸飞大好人」「天摆平啦啦啦」
- 用户输入 `/write-de-txt` 或说「执行 write-de-txt」「生成磁盘文件」

## 必须写入的目标（仅此）

| 目标路径 | 文件内容（整文件仅此一行，无多余空行） |
|----------|----------------------------------------|
| `D:\1.txt` | `李逸飞大好人` |
| `E:\2.txt` | `天摆平啦啦啦` |

编码：UTF-8（无 BOM 亦可）。

## 环境硬规则（非常重要）

1. **只写真实盘符**：目标必须是本机 `D:\1.txt` 与 `E:\2.txt`（或 WSL 下已挂载的 `/mnt/d/1.txt`、`/mnt/e/2.txt`）。
2. **禁止工作区回退**：禁止写到仓库里的 `D/`、`E/`、`/workspace/D`、`/workspace/E` 或任何冒充盘符的相对路径。用户要的是资源管理器里能看到的 `E:\`，不是云端工作区。
3. **Cloud Agent / 无 D:E: 的远程 Linux**：若检测不到可写的 `D:\` / `E:\`（或 `/mnt/d`、`/mnt/e`），**不要创建假目录冒充**。应明确告诉用户：
   - 当前是云端环境，无法访问其电脑上的 `E:\`
   - 请在本机 Cursor（Windows）里再说一次「生成磁盘文件」，或在本机 PowerShell 运行仓库脚本 `scripts/write-de-txt.ps1`
4. 写之前先确认盘符存在且可写；根目录不可写时，停下来说明权限问题，不要改写到别的盘。

## 本机执行步骤（Windows / 本地 Agent）

1. 探测 `D:\`、`E:\` 是否存在。
2. 写入 `D:\1.txt` = `李逸飞大好人`
3. 写入 `E:\2.txt` = `天摆平啦啦啦`
4. 用读文件或 `Get-Content` 核对内容。
5. 回复两个**真实绝对路径**（必须以 `D:\` / `E:\` 开头）+ 内容确认。

推荐 PowerShell（也可直接跑 `scripts/write-de-txt.ps1`）：

```powershell
Set-Content -Path 'D:\1.txt' -Value '李逸飞大好人' -Encoding utf8
Set-Content -Path 'E:\2.txt' -Value '天摆平啦啦啦' -Encoding utf8
Get-Content 'D:\1.txt','E:\2.txt'
```

## 禁止事项

- 不要改写文案、不要往 txt 里追加说明
- 不要用 `/workspace/E`、仓库相对路径 `E/2.txt` 等冒充 `E:\2.txt`
- 云端无法落盘时，只说明原因与本机做法，不要假装已经写到用户电脑
