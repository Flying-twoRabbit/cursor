# 咖啡与美食选购规则

当需求涉及咖啡豆、咖啡粉、咖啡器具、咖啡店、零食、食材、餐厅或外卖时读取。

## 先识别子品类

“咖啡”可能指豆/粉、器具或门店；“美食”可能指包装食品、食材、餐厅或外卖。用户没有说清时先确认，不要混用评价维度。

通用最低信息：

- 预算和购买数量；
- 所在城市或收货地区；
- 口味偏好与明确不喜欢的味道；
- 忌口、过敏原或饮食限制；
- 使用/食用场景、人数和频率。

对严重食物过敏，不能仅凭搜索摘要或评论断言“无过敏原”。要求用户以实物标签和商家书面答复为准；信息无法确认时不推荐该商品。

## 咖啡豆与咖啡粉

### 搜索前确认

- 使用方式：意式机、摩卡壶、手冲、法压、冷萃或直接冲泡；
- 是否有磨豆机，以及需要整豆还是咖啡粉；
- 偏好：明亮果酸、花香茶感、坚果巧克力、醇厚苦甜等；
- 烘焙度、是否接受拼配、单次消耗速度和预算；
- 咖啡因需求，如普通、低因或不限定。

### 核验重点

- 优先确认烘焙日期或明确的发货烘焙规则，不只看保质期；
- 对照处理法、产地、品种、烘焙度和建议冲煮方式；
- 区分商家风味描述与多位饮用者反复提到的实际风味；
- 检查批次变化，旧评价不自动适用于当前产季；
- 按消耗速度推荐包装量，避免为了单价囤积导致风味衰减；
- 说明“最佳赏味期”是经验区间，不冒充统一硬标准。

咖啡豆的三个选择应尽量形成风格差异，同时都适配用户器具。审美升级款可以体现产区、处理法或风味复杂度，但不能只靠包装和稀缺故事抬高评价。

## 咖啡器具

- 先确认已有设备、台面空间、每天杯数和愿意投入的操作/清洁时间；
- 比较核心性能、容错、耗材、清洁、噪音、维修和配件可得性；
- 精确到型号和版本，防止把同名旧款或海外电压版本混入；
- 不以参数更多代表更适合。用户每天只做一杯时，复杂工作流可能是负担；
- 电器只引用可核验的额定参数和合规信息，不自行作安全认证。

## 包装食品、零食与食材

### 核验重点

- 精确到口味、规格和生产商，检查配料表、净含量、储存方式和保质期；
- 单价统一换算为元/100g、元/件或其他合理单位，防止大包装造成虚假便宜；
- 区分原料本身、调味和营销概念，例如“0 蔗糖”不等于无糖；
- 查看近期反馈中的批次稳定性、碎损、漏液、临期、冷链和售后；
- 生鲜结合收货地区、季节、配送时效和坏果赔付，不跨地区套用体验；
- 不给营养治疗、减肥功效或疾病相关购买建议。

性价比应包含吃得完和储存成本。大包装单价低但可能过期时，不列为性价比款。

## 餐厅、咖啡店与外卖

### 搜索前确认

- 城市、商圈或可接受配送范围；
- 到店还是外卖，日期、时段、人数和人均预算；
- 想吃的品类、口味、忌口及用餐场景；
- 对排队、噪音、停车、环境和服务的容忍度。

### 核验重点

- 精确到分店；连锁不同门店的出品、排队和服务不能混为一谈；
- 优先近 3–6 个月有菜名、价格、口味和场景细节的评价；
- 比较多个平台，识别集中发布、同质化文案、只拍环境不谈菜品等种草特征；
- 核对菜单、营业时间、闭店/装修、预约规则和当前团购条件；
- 外卖额外查看配送后口感、包装、分量、漏撒和出餐稳定性；
- 网红热度只能表示人多或曝光高，不能证明好吃。

餐饮三个选择可以分别偏向：

- 最稳妥：近期稳定、符合口味、差评风险明确；
- 性价比：实际可点套餐的人均较低，分量和核心菜仍达标；
- 审美升级：环境、呈现或特色体验更强，同时说明是否牺牲便利或价格。

## 下单/下馆前检查

- [ ] 商品口味、规格、数量或餐厅分店无误
- [ ] 当前价格包含必要运费、包装费或团购限制
- [ ] 忌口和过敏原已从可靠信息确认
- [ ] 咖啡烘焙日期、食品保质期或餐厅近期状态可确认
- [ ] 购买量与实际消耗速度匹配
- [ ] 餐厅预约、排队、停车或外卖配送风险已考虑
