# 衣服与家具选购规则

当需求涉及衣服、鞋包、配饰、家具或普通家居用品时读取。

## 衣服、鞋包和配饰

### 搜索前最少信息

优先从对话中提取，缺失时只追问会改变推荐的问题：

1. 品类和使用场景，例如通勤西装、夏季旅行连衣裙、每天步行的运动鞋；
2. 预算区间；
3. 常穿尺码，以及至少一个更可靠的参照：
   - 衣服：身高、体重和胸/腰/臀中与版型最相关的数据；
   - 鞋：脚长、脚宽或已知合脚品牌尺码；
   - 包：要装的最大物品及期望背法；
4. 想要的版型、颜色、材质感与明确排斥项；
5. 是否愿意干洗、手洗、熨烫或接受易皱材质。

涉及贴身衣物等隐私数据时只询问完成当前推荐所需的信息，不要求用户建立永久档案。

### 核验重点

- 必须以具体商品的尺码表为准，不使用“平时穿 M 就买 M”。
- 区分模特展示、平铺尺寸和人体净尺寸；说明是否需要预留活动量。
- 读取纤维成分和比例，不把“羊毛感”“真丝级”“科技棉”等营销词当成材质。
- 结合结构判断风险：肩线、裆长、裤长、腰头、鞋楦、鞋跟高度、包带长度和自重。
- 查找洗后缩水、起球、掉色、透肤、粘毛、闷热、磨脚、五金耐用等具体追评。
- 颜色受拍摄和屏幕影响时明确提醒，优先寻找自然光买家图和退换政策。
- 推荐前确认该颜色/尺码仍在售，并记录具体 SKU。

### 常见误判

- 小红书穿搭好看，不等于同一身材和场景下合适；
- 高克重不自动代表面料好，低克重也不自动代表廉价；
- “显瘦”“不挑人”“久走不累”属于待验证宣传；
- 销量和主播口播不能替代尺码、材质与长期追评；
- 低价但尺码不稳定、退货运费高，不是实际性价比。

### 衣服下单检查

- [ ] 具体尺码表与用户关键尺寸留有合理余量
- [ ] 已核对颜色、版型、材质比例和护理方式
- [ ] 已查看该 SKU 而非其他颜色/批次的评价
- [ ] 已确认退换期限、运费和吊牌要求
- [ ] 收货后先在室内自然光试穿，不洗涤、不剪吊牌

## 家具与普通家居

### 搜索前最少信息

1. 家具类型、主要使用者和使用频率；
2. 总预算是否包含运费、上楼、安装和旧家具处理；
3. 摆放空间的可用长、宽、高，以及插座、踢脚线、开门和走道限制；
4. 入户路径最窄处：楼道、电梯、门框和转角；
5. 风格、颜色和现有家具；有宠物、儿童或扫地机器人时一并考虑；
6. 对材质、气味、清洁和维护的接受程度。

用户没有量尺寸时暂停具体推荐，先给测量清单。图片无法可靠推断绝对尺寸。

### 核验重点

- 对照商品外径、坐深/坐高、桌下净高、抽屉打开尺寸等实际使用尺寸；
- 区分实木、实木贴皮、人造板、密度板和营销命名，核对主材与辅材；
- 软体家具查看填充材料、密度、回弹和套面是否可拆洗；
- 柜桌类查看连接方式、承重依据、五金品牌/规格和背板抽屉结构；
- 沙发、床垫和椅子结合身高、坐姿/睡姿与软硬偏好，不按单一热门结论推荐；
- 查近期追评中的异响、塌陷、开裂、变形、气味、色差、安装和售后；
- 确认包装尺寸能否进门，而不只是成品尺寸；
- 大件退货时核对拆装、包装、上门取件和运费责任。

不具备实验条件时，不自行断言甲醛、安全承重或使用寿命。引用商家检测报告时标明报告对象、标准、日期和它仍属于商家提供的证据。

### 家具下单检查

- [ ] 摆放尺寸与活动空间都足够
- [ ] 包装可以通过楼道、电梯、门框和转角
- [ ] 运费、上楼、安装和退货成本已计入
- [ ] 具体颜色、面料、左右方向和组合模块无误
- [ ] 材质描述与用户维护能力匹配
- [ ] 收货验货、破损拒收和售后流程已确认
