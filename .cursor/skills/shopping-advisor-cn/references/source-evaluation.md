# 选购信源判断

建立候选池和核验证据时读取。目标是让推荐可追溯，不是追求链接数量。

## 信源分工

不同来源只证明它擅长的部分：

| 来源 | 适合确认 | 不能单独证明 |
|---|---|---|
| 品牌官网、旗舰店详情 | 型号、规格、官方价格、材质/配料声明、售后条款 | 实际体验、耐用性、同类最佳 |
| 独立实验或规范化测评 | 同条件性能比较、测量结果、测试方法 | 当前淘宝价格、每个人的主观偏好 |
| 长期购买追评 | 起球、塌陷、故障、风味稳定、售后等长期问题 | 问题发生率、所有批次都相同 |
| 小红书、抖音等社区内容 | 使用场景、搭配灵感、近期热点和潜在线索 | 无偏排名、准确参数、普遍适用性 |
| 淘宝评价与问大家 | 具体 SKU 的收货、尺码、批次和售后线索 | 未购买者不可见的真实总体质量 |
| 餐饮平台近期评价 | 分店菜品、排队、环境、外卖稳定性的线索 | 所有人都会喜欢、其他分店相同 |
| 商家客服答复 | 当前库存、可选规格、个别售后确认 | 独立质量证明 |
| 返利、优惠和价格聚合站 | 发现可能的历史价格或商品编号 | 当前成交价、在售状态、质量和独立体验 |

## 最低核验要求

每个最终候选至少需要：

1. 一个当前可识别商品、品牌或门店的一手页面；
2. 一个与用户最关心风险相关的独立信息来源；
3. 价格、规格和评价指向同一个型号、SKU、批次或分店；
4. 至少一个具体缺点或尚未确认的信息。

“多个来源”不等于复制同一新闻稿或商家素材的多个页面。若几个账号使用相同文案、图片、参数错误或发布时间高度集中，按一个营销源处理。

只有能识别作者或机构、发布时间、实际使用/测试情境，并看得出内容不是商品文案转载时，才称为“独立测评”或“独立反馈”。来源归属不明的导购站、自动聚合页、内容农场、搜索摘要和只复述参数的文章只能用于发现线索，不能提高推荐可信度。

## 社区内容的降噪

优先保留：

- 展示购买时间、具体型号、使用时长和实际环境；
- 同时描述优缺点，并给出可观察细节；
- 评论区有针对尺寸、批次、做法或售后的追问与补充；
- 长期更新或追评与初次体验有区别；
- 与商品详情及其他用户反馈能够互相印证。

降低权重：

- 只有开箱、滤镜图、情绪词或“闭眼入”；
- 未说具体型号、规格、价格和使用时间；
- 商品链接、优惠码或直播转化是主要内容；
- 多个账号在短期内发布同一卖点和近似脚本；
- 用“销量第一”“明星同款”“网红店”代替体验证据；
- 把极端单条好评或差评当成总体结论。

不要试图断言某篇内容一定是广告，除非有明确披露。可以客观写“商业关系不明，因此只作为线索”。

## 处理冲突

来源冲突时先检查：

- 是否为不同型号、年份、颜色、尺码、批次或分店；
- 测试条件和使用场景是否不同；
- 评价时间是否跨越改款、换供应商或菜单调整；
- 主观偏好是否被误写成客观性能；
- 商家是否更新了详情页但旧评论仍在。

无法解释时同时展示冲突，并降低推荐把握。不要挑选最支持既定结论的来源。

## 价格和链接

- 记录看到价格的日期、平台、规格及优惠前提；
- 区分标价、券后价、会员价、直播价、定金尾款和多件折算价；
- 不把搜索摘要中的旧价格写成当前成交价；
- 返利、导购和价格聚合页只能作为价格线索，必须回到用户指定平台核实，且不能充当独立质量证据；
- 淘宝国际镜像或搜索结果可帮助定位同一商品 ID，但大陆账号下的 SKU、库存和价格仍需在淘宝 App 内确认；
- 链接优先顺序：具体商品/门店页 → 品牌具体型号页 → 能定位该商品的搜索结果；
- 无法取得稳定直链时写明平台、店铺、完整商品名和搜索词，同时标注“直链未核实”；
- 不创建看似真实的淘宝、抖音或短链接。

## 结论措辞

证据强度与措辞保持一致：

- 多个可靠来源一致：`目前证据较一致地表明……`
- 只有具体用户反馈：`近期多条具体反馈提到……，但无法推断发生比例`
- 只有商家声明：`商家标注……，尚无独立证据核实`
- 信息冲突：`关于……存在冲突，因此把它列为下单前确认项`
- 无法访问：`当前未能核实……，不将其作为推荐依据`
