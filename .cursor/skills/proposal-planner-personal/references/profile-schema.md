# 跨设备求婚资料格式

仅在 `.cursor/private/proposal-planner/profile.md` 不存在或需要更新时读取。该路径按用户明确选择通过 Git 同步，仓库协作者可见；只记录脱敏且确实需要跨设备使用的背景。

```markdown
# 求婚策划私密资料

## 关系与共识
- 双方是否讨论过结婚：
- 对方明确表达过的态度：
- 在一起时间：
- 共同经历：
- 对方欣赏用户的地方：
- 用户欣赏对方的地方：

## 对方偏好
- 仪式感：
- 公开/私密偏好：
- 摄影录像接受度：
- 亲友现场接受度：
- 喜欢的风格、颜色、花、音乐和食物：
- 明确雷区：

## 时间、地点与预算
- 目标日期范围：
- 优先城市/区域：
- 总预算：
- 是否包含戒指：
- 是否包含宾客交通住宿：
- 可接受室内/户外：

## 戒指
- 状态：未选 / 已选 / 已到手
- 尺寸是否确认：
- 由谁保管：

## 宾客与供应商
- 预计宾客人数：
- 关键协助者：
- 宾客出发城市：
- 是否需要摄影：
- 是否需要录像：
- 是否需要 Party：
- 是否需要住宿：

## 故事素材
- 高中阶段：
- 大学异地阶段：
- 来杭州后的阶段：
- 重要地点：
- 重要日期：
- 歌曲、食物、物件或内部梗：
- 可使用的照片/语音/视频：

## 保密
- 对方可能察觉的信号：
- 合理到场理由：
- 不应知情的人：
- 私密沟通方式：

## 待确认
- [ ] ...
```

## 数据最小化

- 联系方式只写角色和代号，例如“大学室友A”，不要写真实手机号。
- 供应商联系方式、合同、报价单和完整沟通记录不要写入此档案。
- 戒指藏放位置不记录；只记录保管责任人。
- 求婚完成后，询问用户是否删除日期、行程和保密信息。
